# Plain_text_AI-generated_video_prompt
一个提示词，可以让只能输出文本的ai（如deepseek-R1）做视频！

【AI生成视频提示词】

你好，请帮我生成一段视频

你需要先明确：你不是一个“直接吐出 MP4”的模型，而是一个代码驱动动画导演 + 前端工程师。你不能直接画像素，也不能抽卡，你必须通过写代码 → 控制时间轴 → 逐帧渲染 → 合成视频的方式来完成。

具体工作流程如下：

一、你怎么做

1. 先理解我的视频主题，把它拆成 5～8 个镜头（分镜）。
2. 为每个镜头写可运行的动画代码（HTML + CSS + SVG / Canvas / JS，或 Three.js / GSAP）。
3. 用代码定义所有视觉元素：图形、文字、颜色、位置、大小、运动轨迹。
4. 用时间轴控制动画：精确到秒，定义每一秒画面该做什么（如：第3秒圆放大、第5秒文字淡入、第10秒镜头推进）。
5. 所有画面必须由代码生成，不依赖任何外部图片、视频、3D模型文件。
6. 动画必须自动播放，无需用户交互，循环或按时间轴线性推进。

二、你使用什么工具

- 语言：HTML + CSS + JavaScript
- 动画：CSS animation / requestAnimationFrame / GSAP / Canvas 2D / Three.js
- 字体：系统字体或 Google Fonts（如 Noto Sans SC）
- 渲染：无头浏览器（如 Puppeteer）逐帧截图（30fps）
- 合成：FFmpeg 将图片序列打包为 MP4（H.264，1920×1080，30fps）

三、做视频需要注意什么

1. 时间轴必须精确：每一幕的起止时间、画面动作、字幕出现时间都要写死。
2. 画面不能乱：禁止无意义几何堆砌、禁止随机闪烁、禁止镜头乱晃。
3. 文字必须清晰：字幕用大字号、高对比度，每句不超过20字，关键词高亮。
4. 风格必须统一：全片色调、线条粗细、动画缓动曲线保持一致。
5. 转场必须自然：用淡入淡出、位移、缩放，不用硬切。
6. 禁止项：不要真人照片、不要乱码文字、不要水印、不要调试按钮、不要鼠标光标。

四、做完视频之后又要怎么样

1. 渲染前自检：几何是否穿模、文字是否溢出、时间轴是否对齐、首尾是否闭环。
2. 逐帧检查：确保每一帧画面正确，没有空白帧、花屏、卡顿。
3. 合成后检查：音画同步（如有配音）、画面流畅度、文件大小。
4. 输出：最终 MP4 文件，附带分镜表 + 时间轴文档 + 源代码。

五、过程中你又需要怎么样

1. 先输出分镜表（表格：幕号 / 时间 / 画面描述 / 字幕 / 动效）。
2. 再输出完整代码（一个 HTML 文件，包含所有 CSS 和 JS，可直接打开运行）。
3. 如果代码太长，可分段输出，但必须标注拼接顺序。
4. 每一步完成后，确认再继续下一步。
5. 如果中途出错，先修正代码，再重新渲染，不要跳过错误。
